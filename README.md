# 🎙️ Desktop-Based Voice-Controlled Personal Assistant (Python)

This is a "desktop-based voice-controlled personal assistant" built using Python.  
The assistant runs "locally on the system" and requires the project files to function.  
It is "not a web-based application" and does "not use any domain or cloud hosting".

The assistant listens to voice commands through a microphone and performs system-level operations such as volume control, brightness adjustment, and YouTube automation.

---

## ⚠️ Important Note

- ❌ Not a website
- ❌ Not domain-hosted
- ❌ Cannot run independently without project files
- ✅ Runs locally on a desktop system
- ✅ Requires microphone and OS-level permissions

---

## 🚀 Features

- 🎤 Real-time voice recognition (local execution)
- 🔊 System volume control
- 💡 Screen brightness control
- ▶️ Voice-based YouTube search and automation
- 🖥️ Keyboard and mouse automation
- 📝 Command logging for debugging
- 🔒 Works entirely on the local machine

---

## 🛠️ Tech Stack

- Programming Language: Python  
- Speech Recognition: SpeechRecognition (Google Speech API)
- Desktop Automation: PyAutoGUI
- Audio Control: Pycaw
- Brightness Control: screen-brightness-control
- Window Handling: win32gui
- Browser Control: webbrowser
- Logging: Python logging module
